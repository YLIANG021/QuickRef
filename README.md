# QuickRef

QuickRef helps you work with camera reference images in Blender more efficiently. Add, view, and adjust reference images with ease, so you can match compositions and refine scenes faster.

- 🖼️ Quickly manage and switch between multiple reference images
- ✋ Move, scale, and rotate reference images directly without configuring complex settings
- 🎚️ Adjust opacity and visibility from the top bar
- 🎬 Quickly fine-tune perspective and object depth
- ⚡ Create a camera from the current view

---

## Add-on Location

1. In the 3D Viewport, press `N`, then open `View` → QuickRef in the sidebar.

### 3. ✋ Adjust Reference Images Directly in Camera View

After clicking `Adjust`, drag the reference image directly in the 3D Viewport to align it. This intuitive workflow replaces the need to edit complex parameters.

- `G`: Move　`S`: Scale　`R`: Rotate
- `Shift`: Fine adjustment　`Ctrl`: Value snapping
- Left-click: Confirm　Right-click: Cancel

### 4. 🎬 Match the Composition with Two Adjustment Modes

When the scene's perspective or the relative depth of its objects does not match the reference image, you can make quick adjustments while preserving the composition.

Choose an adjustment mode under `Tools`, make sure the object you want to adjust is selected, then click the play icon to begin.

#### Adjust Perspective

After selecting an object, change the perspective while keeping the object's appearance in the frame unchanged. This makes perspective adjustments faster and more intuitive.

(The add-on automatically compensates for changes to perspective settings and camera position, saving you from having to reposition the camera manually after adjusting the perspective.)

### 5. 🎚️ Keep Frequently Used Controls Close at Hand

## More Features

- Duplicate a camera together with its reference image settings
- Quickly switch projection type, focal length, and orthographic scale
- Replace missing image files directly while preserving the existing reference image settings
- Adjust perspective or object depth based on the current selection
- View mouse controls and confirmation instructions in on-screen prompts
