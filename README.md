# 👉QuickRef👈

### 让 Blender 里的参考图工作流更快、更清晰、更顺手。

QuickRef 提供两种参考图模式：一套面向摄像机取景，一套面向多视图建模。添加、切换、调整和构图控制，都集中在一个面板里完成。让你快速匹配镜头、调整场景。

## 📍 插件位置

在 3D 视图中按 `N` 打开侧栏，进入 `视图` → QuickRef。

支持 English、简体中文、繁體中文、日本語、한국어、Deutsch、Français、Español、Italiano、Polski、Português、Русский 和 Tiếng Việt。


## 📷 模式 1：摄像机参考

### 1. 一处管理，快速切换

集中管理多张摄像机参考图，随时切换、调整和替换，不必反复打开 Blender 默认设置。

<img width="810" height="480" alt="August 22 (2)" src="https://github.com/user-attachments/assets/8c693a33-f255-40ca-99c6-9b044628fb0e" />

### 2. 从当前视图一键生成摄像机

找到理想角度后点击一次，即可创建匹配的摄像机。视角和构图直接延续，灵感不会因为手动对齐而中断。

<img width="810" height="480" alt="8月27日" src="https://github.com/user-attachments/assets/84faef1a-a42c-45cf-911d-c2f471ae0039" />

### 3. 在摄像机视图里直接调整参考图

点击 `调整`，直接在视图中移动、缩放和旋转参考图。支持 `G`、`S`、`R`，配合 Shift 精调和 Ctrl 吸附，比输入参数更快更直观

<img width="810" height="480" alt="August 22 (1)" src="https://github.com/user-attachments/assets/57dd58ec-4217-4f41-9564-89ae4ea1c764" />

## 🧭 模式 2：多视图参考

### 1. 六个方位，一套清晰的建模参考

将 Image Empty 按前方、后方、左方、右方、上方和下方分别管理。切换方位即可查看对应列表，多角度建模、匹配和检查一目了然。

选中物体并选好方位后，添加图像就会自动放到合适的初始位置和方向，不用再手动调整

<img width="810" height="480" alt="8月29日(3)" src="https://github.com/user-attachments/assets/7c58c1b8-359b-44e2-8c88-635d7e82525b" />

### 2. 独立列表，灵活组合

和摄像机视图模式一样，一个方位可以添加多张参考图，打开列表即可快速切换，查看不同角度和细节更方便。

## 🛠️ 3. 工具与通用能力

### 1. 常用控制始终在手边（两种模式都支持）

参考图的不透明度和可见性可从窗口顶栏快速控制，不打断视图，也不再影响你开其他插件

<img width="820" height="460" alt="9月1日(2)" src="https://github.com/user-attachments/assets/d7a1b4f5-4ec7-47ed-a12d-1adde3c6c9af" />

多视图参考中的锁定、前面 / 双面 / 后面、仅轴向显示和重置旋转等控制，可统一作用于全部多视图参考图。

### 2. 调整摄像机透视，构图依然稳定（专属摄像机参考模式）

改变焦距时，物体总会跟着变大或变小，还得手动拉近或拉远摄像机？QuickRef 会同步补偿摄像机和目标距离，让你只管改变焦距，画面构图始终保持稳定。

<img width="820" height="460" alt="9月1日" src="https://github.com/user-attachments/assets/be2adfcf-ef9b-4931-ab96-fbbf3a52ba68" />

### 3. 调整物体距离，保持画面外观（专属摄像机参考模式）

物体深度或遮挡关系不对时，调整物体距离，同时保持参考图中的外观不变；编辑模式也能使用。🧩
